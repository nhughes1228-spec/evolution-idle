# Evolution Idle

A tiny GitHub Pages-ready starter prototype inspired by civilization/discovery idle games.

## How to use

1. Create a new GitHub repository.
2. Upload these files directly into the root of the repo:
   - `index.html`
   - `style.css`
   - `game.js`
   - `README.md`
3. In GitHub, go to **Settings → Pages**.
4. Set the source to **Deploy from a branch**.
5. Choose the `main` branch and `/root` folder.
6. Open the GitHub Pages URL once it appears.

## Current prototype features

- Click to generate Biomass
- Buy discoveries
- Unlock eras and organism names
- Passive biomass per second
- Local save using browser localStorage
- Timeline of discoveries
